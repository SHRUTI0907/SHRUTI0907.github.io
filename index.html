| ABOUT ME |

I didn't set out to build four separate projects. I set out to answer one question, over and over: can I trust what this data — or this AI — is telling me?

That question is why my portfolio reads like a path rather than a pile of projects. It starts with signal — pulling structure out of 250,000 unstructured customer complaints. It moves to risk — using that same skill to catch corporate distress before it becomes a headline. Then access — building an agent that lets anyone ask a database a question in plain English. And finally trust — because once you've shipped a few AI agents, the only question that matters is whether you can prove they're working.

I'm currently pursuing my Master's in Business Analytics at Columbia University, with hands-on experience building Monte Carlo risk engines, forecasting pipelines, and LLM-grounded decision tools for real companies. I care less about using AI because it's trendy, and more about using it where it can be measured, explained, and trusted.
